# Рыбная лавка капитана Селедкина

Чистая статическая пересборка исходного сайта [ks.fish](https://ks.fish/):
с сохранёнными авторскими текстами, фотографиями, бело-синей палитрой
и морским первым экраном. В проекте нет Next.js, React, сборщика приложения и
клиентского фреймворка. GitHub Pages публикует готовые HTML, CSS, JavaScript
и изображения напрямую.

Согласованные отличия от публичного исходника: используется переданный
перерисованный логотип, авторская фотография кота Лосося и гарнитура
Iowan Old Style. Сломанный блок новостей и всплывающее предупреждение о ценах
не перенесены.

## Структура

- index.html — главная: морской первый экран с пятью свежими записями,
  ассортимент и цены, доставка, контакты, история лавки, «Свежий улов»,
  «Судовой журнал» и содержательный подвал;
- catalog/index.html — полный каталог с действующими ценами;
- catalog/catalog.js — поиск и фильтры поверх готового HTML-прайса;
- scripts/build-catalog.mjs — сборка 114 позиций и ссылок заказа из единых данных;
- robots.txt и sitemap.xml — карта двух индексируемых страниц Pages-версии;
- assets/styles.css — общая адаптивная визуальная система исходного сайта;
- assets/theme.js — тема по московскому расписанию с сохраняемым ручным выбором
  «Ночная вахта / Дневная вахта»;
- assets/typography.js — единые правила экранной типографики для статических
  страниц и динамического каталога;
- assets/interface-motion.js — переходы «Меню / Закрыть» и «Солнце / Луна»
  на исходных знаках; независимое улучшение с прежним статическим fallback;
- assets/morphicons-*.js — локальный DOM-драйвер Morphicons 1.7.1 и его ядро,
  без CDN и клиентского фреймворка; лицензия в assets/morphicons.LICENSE.txt;
- assets/catalog-data.js — 114 товарных позиций;
- assets/logo-redrawn-sea.svg и assets/logo-redrawn-jelly-mask.svg — единый
  живой логотип и точная маска его контекстного материала;
- assets/logo-catch-squid.svg и assets/logo-catch-squid-night.svg —
  изолированный черновик сменной серии; живой интерфейс его не подключает;
- assets/favicon-16.png, assets/favicon-32.png и assets/apple-touch-icon.png —
  принятый фотографический значок с котом Лососем;
- assets/salmon-cat.jpg — переданная авторская фотография кота Лосося;
- assets/hero-sea.mp4 и assets/hero-sea-night.mp4 — дневной и ночной варианты
  моря; соответствующие poster-файлы собраны из кадров самих роликов;
- assets/fish-pattern.svg — переданный векторный паттерн с рыбами;
- assets/journal-680.jpg … assets/journal-684.jpg — авторские изображения
  пяти вручную отобранных записей «Судового журнала»;
- ACCESSIBILITY.md — обязательный стандарт WCAG 2.2 AA и ручной выпускной
  gate для всех страниц и состояний;
- остальные JPG — локальные оригинальные изображения
  публичного ks.fish, без зависимости от Tilda CDN;
- scripts/logo-variants/squid.svg — редактируемый мастер контекстного знака;
- scripts/build-logo-variants.mjs — детерминированная сборка только
  изолированных черновиков сменной серии;
- scripts/check-static.mjs и tests/*.test.mjs — механический gate без зависимостей;
- tests/browser/ и playwright.config.mjs — сценарии Chromium и WebKit,
  включая axe-проверки доступности.

Для выразительного набора используется системная Iowan Old Style с безопасными
serif-фолбэками. Функциональный текст набирается Golos Text, который
подключается с Google Fonts и имеет системный sans-serif-фолбэк.

По умолчанию цветовая тема следует часам работы лавки в Москве:
дневная с 11:00 до 20:00, ночная — в остальное время. Системная настройка
используется только при недоступности московского времени. Кнопка «Ночная
вахта / Дневная вахта» сохраняет явный выбор в браузере и применяет его на
главной, в каталоге и на странице 404 до загрузки CSS, без вспышки другой темы.
Авторские фотографии не фильтруются.

## Локальный запуск

~~~bash
pnpm dev
~~~

После запуска сайт доступен по адресу
[http://localhost:4173/](http://localhost:4173/).

Экспериментальные, не подключённые к сайту варианты сменной серии
пересобираются отдельной командой:

~~~bash
pnpm build:logo-drafts
~~~

## Проверка

Прайс хранится в assets/catalog-data.js. После изменения товаров или цен:

~~~bash
pnpm build:catalog
pnpm lint
~~~

Генератор обновляет отмеченные области catalog/index.html; lint проверяет,
что HTML совпадает с данными. В Git нужно включать и данные, и обновлённый HTML.
Все позиции и ссылки заказа доступны без JavaScript, в том числе при ошибке
загрузки модуля. JavaScript добавляет поиск, фильтры и состояние в URL:
`?q=нерка&category=frozen-fish`. Старые ссылки `#category-frozen-fish` также поддерживаются.
Ссылки заказа открывают черновик сообщения с конкретной позицией, описанием
и ценой; сами ничего не отправляют.

Для воспроизводимого обновления локального драйвера иконок:

~~~bash
pnpm install --frozen-lockfile --ignore-scripts
pnpm build:icons
pnpm build:icons --check
~~~

Версия Morphicons зафиксирована в devDependencies и lockfile. Готовые JS-файлы
хранятся в Git и публикуются напрямую. Пружина задаётся одним `iconSpring`;
reduced motion отключает морфинг, включая уже начатый переход. Геометрия
кнопок и подписи не управляются модулем анимации.

~~~bash
pnpm lint
pnpm test
~~~

Обе команды запускаются стандартным Node.js. Установка пакетов для проверок
не требуется: драйвер иконок уже находится в assets. Проверки также охватывают семантическую основу доступности,
неизменяемые пороги контраста, поддержку системных режимов, модальность меню
и наличие полного контракта из ACCESSIBILITY.md.

Для браузерного gate требуется установка тестовых зависимостей и браузеров:

~~~bash
pnpm install --frozen-lockfile --ignore-scripts
pnpm exec playwright install chromium webkit
pnpm test:browser
~~~

Playwright сам запускает локальный сервер. Набор проверяет каталог без JS
и при ошибке модуля, черновики заказа, поиск и историю URL, якорь контактов,
приоритет Escape, карусель во всех пяти состояниях, обе темы, reflow 320 px,
увеличение текста, пользовательские интервалы и контрастные режимы.
Скриншоты и диагностические трассы сохраняются в test-results/.
Автоматические проверки не заменяют визуальную приёмку реальных экранов.

## Публикация

Workflow .github/workflows/pages.yml выполняет механический и браузерный gate,
сохраняет браузерные артефакты, собирает в служебную
папку только публичные статические файлы и публикует их на GitHub Pages.

Переключение домена ks.fish остаётся отдельным шагом после визуальной приёмки
Pages-версии: сначала добавить CNAME, затем изменить DNS и повторно проверить
публичный сайт.
