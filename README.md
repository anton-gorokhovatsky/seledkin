# Рыбная лавка капитана Селедкина

Независимая статическая версия сайта [ks.fish](https://ks.fish/), перенесенная с Tilda. В репозитории лежат собственные изображения проекта, весь каталог в данных и адаптивная одностраничная витрина.

Обязательные продуктовые, визуальные, типографические и accessibility-правила собраны в [`AGENTS.md`](./AGENTS.md).

## Что изменилось

- сохранены логотип, фотографии, адрес, контакты, история лавки и полный прайс-лист;
- каталог вынесен в `app/products.ts`, поэтому цены можно править без визуального конструктора;
- добавлены поиск, фильтры по категориям, адаптивное меню и быстрый заказ с телефона;
- типографика построена как непрерывная шкала, а интерфейс учитывает клавиатуру, масштабирование и `prefers-reduced-motion`;
- проект собирается в обычные статические файлы и публикуется через GitHub Pages;
- цены явно помечены датой исходного прайс-листа — январь 2026 года.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Проверка production-сборки:

```bash
pnpm test
```

## Публикация

Workflow `.github/workflows/pages.yml` публикует ветку `main` по адресу `https://anton-gorokhovatsky.github.io/seledkin/`.

Переключение домена `ks.fish` стоит делать отдельным шагом после приемки GitHub-версии: убрать `NEXT_PUBLIC_BASE_PATH`, добавить `public/CNAME` и только затем изменить DNS. До этого действующий сайт на Tilda остается нетронутым.
