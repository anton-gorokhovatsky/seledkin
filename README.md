# Рыбная лавка капитана Селедкина

Статическая контрольная копия действующего сайта [ks.fish](https://ks.fish/), перенесенная с Tilda. Она сохраняет исходную последовательность, пропорции, тексты и визуальный характер страницы, чтобы дальше улучшать сайт небольшими проверяемыми шагами.

Обязательные продуктовые, визуальные, типографические и accessibility-правила собраны в [`AGENTS.md`](./AGENTS.md).

## Что сохранено

- исходные логотип, фотографии, морской первый экран, длинная история лавки, карта и финальный блок с котом;
- порядок и композиция секций на десктопе и мобильном, включая отдельную мобильную подачу первого экрана;
- полный прайс-лист за январь 2026 года и оригинальные фильтры по категориям;
- уведомление о меняющихся ценах и исходные способы заказа через Telegram и WhatsApp.

При этом каталог уже вынесен в `app/products.ts`, страница собирается без Tilda, а семантика, клавиатурный фокус, reflow и `prefers-reduced-motion` подготовлены для дальнейшей работы. Неработающая внешняя лента новостей зафиксирована как спокойный плейсхолдер — визуально на том же месте, но без зависимости от виджета Tilda.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Проверка production-сборки:

```bash
pnpm test
```

## Публикация

Workflow `.github/workflows/pages.yml` публикует ветку `main` по адресу `https://anton-gorokhovatsky.github.io/seledkin/`.

Переключение домена `ks.fish` стоит делать отдельным шагом после приемки GitHub-версии: убрать `NEXT_PUBLIC_BASE_PATH`, добавить `public/CNAME` и только затем изменить DNS. До этого действующий сайт на Tilda остается нетронутым.
