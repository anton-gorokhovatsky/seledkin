# Рыбная лавка капитана Селедкина

Статический сайт [ks.fish](https://ks.fish/), перенесенный с Tilda и пересобранный как редакционная история лавки. Авторские тексты Олега, узнаваемые фотографии, логотип и морской характер сохранены; сценарий, типографика и функциональные пути обновлены.

Обязательные продуктовые, визуальные, типографические и accessibility-правила собраны в [`AGENTS.md`](./AGENTS.md).

## Что сохранено

- исходные логотип, фотографии, морской первый экран, история Олега, карта и финальный блок с котом Лососем;
- авторские формулировки и интонация Олега — тексты заново скомпонованы, но не переписаны;
- отдельная страница полного каталога с поиском, категориями и запросом наличия конкретной позиции; источник цен датирован январём 2026 года, а месяц проверки актуальности обновляется автоматически;
- три вручную отобранные публикации из телеграм-канала Олега в разделе «Судовой журнал»;
- уведомления о меняющихся ценах и исходные способы заказа через телеграм и WhatsApp;
- локальное фоновое видео первого экрана и статичный постер для уменьшенного движения;
- раскрывающийся виджет связи с телеграмом, WhatsApp и телефоном.

Каталог хранится в `app/products.ts`, обе страницы собираются без Tilda. Семантика, клавиатурный фокус, reflow, увеличенный контраст и `prefers-reduced-motion` входят в обязательный gate проекта. Автоматической новостной ленты нет: «Судовой журнал» состоит только из отобранных записей с прямыми ссылками на первоисточник.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Проверка production-сборки:

```bash
pnpm test
```

## Публикация

Workflow `.github/workflows/pages.yml` публикует ветку `main` по адресу `https://anton-gorokhovatsky.github.io/seledkin/`.

Переключение домена `ks.fish` стоит делать отдельным шагом после приемки GitHub-версии: убрать `NEXT_PUBLIC_BASE_PATH`, добавить `public/CNAME` и только затем изменить DNS. До этого действующий сайт на Tilda остается нетронутым.
