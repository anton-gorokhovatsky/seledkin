# Рыбная лавка капитана Селедкина

Чистая статическая пересборка исходного сайта [ks.fish](https://ks.fish/):
с сохранёнными порядком секций, фотографиями, бело-синей палитрой, масштабом
первого экрана и общей композицией. В проекте нет Next.js, React, сборщика и
клиентского фреймворка. GitHub Pages публикует готовые HTML, CSS, JavaScript
и изображения напрямую.

Согласованные отличия от публичного исходника: используется переданный
перерисованный логотип, авторская фотография кота Лосося и гарнитура
Iowan Old Style. Сломанный блок новостей и всплывающее предупреждение о ценах
не перенесены.

## Структура

- index.html — главная: морской первый экран с пятью свежими записями,
  ассортимент и цены, «Свежий улов», доставка, контакты, история лавки,
  «Судовой журнал» и содержательный подвал;
- catalog/index.html — полный каталог с действующими ценами;
- catalog/catalog.js — нативный поиск, фильтры и ссылки для уточнения наличия;
- robots.txt и sitemap.xml — карта двух индексируемых страниц Pages-версии;
- assets/styles.css — общая адаптивная визуальная система исходного сайта;
- assets/theme.js — системная и сохраняемая между страницами тема
  «Ночная вахта / Дневная вахта»;
- assets/typography.js — единые правила экранной типографики для статических
  страниц и динамического каталога;
- assets/catalog-data.js — 114 товарных позиций;
- assets/logo-redrawn-sea.svg и assets/logo-redrawn-jelly-mask.svg — единый
  живой логотип и точная маска его контекстного материала;
- assets/logo-catch-squid.svg и assets/logo-catch-squid-night.svg —
  изолированный черновик сменной серии; живой интерфейс его не подключает;
- assets/favicon-16.png, assets/favicon-32.png и assets/apple-touch-icon.png —
  принятый фотографический значок с котом Лососем;
- assets/salmon-cat.jpg — переданная авторская фотография кота Лосося;
- assets/hero-sea.mp4 и assets/hero-sea-night.mp4 — дневной и ночной варианты
  моря; соответствующие poster-файлы собраны из кадров самих роликов;
- assets/fish-pattern.svg — переданный векторный паттерн с рыбами;
- assets/journal-680.jpg … assets/journal-684.jpg — авторские изображения
  пяти вручную отобранных записей «Судового журнала»;
- ACCESSIBILITY.md — обязательный стандарт WCAG 2.2 AA и ручной выпускной
  gate для всех страниц и состояний;
- остальные JPG — локальные оригинальные изображения
  публичного ks.fish, без зависимости от Tilda CDN;
- scripts/logo-variants/squid.svg — редактируемый мастер контекстного знака;
- scripts/build-logo-variants.mjs — детерминированная сборка только
  изолированных черновиков сменной серии;
- scripts/check-static.mjs и tests/ — механический gate без зависимостей.

Для выразительного набора используется системная Iowan Old Style с безопасными
serif-фолбэками. Функциональный текст набирается Golos Text, который
подключается с Google Fonts и имеет системный sans-serif-фолбэк.

По умолчанию цветовая тема следует системной настройке. Кнопка «Ночная
вахта / Дневная вахта» сохраняет явный выбор в браузере и применяет его на
главной, в каталоге и на странице 404 до загрузки CSS, без вспышки другой темы.
Авторские фотографии не фильтруются.

## Локальный запуск

~~~bash
pnpm dev
~~~

После запуска сайт доступен по адресу
[http://localhost:4173/](http://localhost:4173/).

Экспериментальные, не подключённые к сайту варианты сменной серии
пересобираются отдельной командой:

~~~bash
pnpm build:logo-drafts
~~~

## Проверка

~~~bash
pnpm lint
pnpm test
~~~

Обе команды используют только встроенные возможности Node.js. Установка
пакетов не требуется. Они также проверяют семантическую основу доступности,
неизменяемые пороги контраста, поддержку системных режимов, модальность меню
и наличие полного контракта из ACCESSIBILITY.md.

## Публикация

Workflow .github/workflows/pages.yml проверяет проект, собирает в служебную
папку только публичные статические файлы и публикует их на GitHub Pages.

Переключение домена ks.fish остаётся отдельным шагом после визуальной приёмки
Pages-версии: сначала добавить CNAME, затем изменить DNS и повторно проверить
публичный сайт.
