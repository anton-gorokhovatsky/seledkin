# Задачи текущего выпуска

Это канонический список задач текущего выпуска. Коммит, зелёные проверки
или сам факт публикации не закрывают пункт: задача считается выполненной только
после проверки реального результата на десктопе и мобильном и явной приёмки.

Работа ведётся сверху вниз небольшими самостоятельными выпусками. Исправление
одного пункта не должно попутно менять уже принятую композицию соседних блоков.

## В первую очередь

- [x] **Заново собрать раздел «О нас».** Не дорабатывать непринятую
  трёхколоночную версию. Сохранить авторский текст Олега и вернуть крупные
  исходные фотографии без квадратного кадрирования и `object-fit: cover`.
  Построить ясную последовательность чтения и устойчивую общую сетку; проверить
  весь раздел на реальных десктопном и мобильном рендерах.
- [x] **Довести фавикон.** Взять авторскую фотографию кота Лосося, собрать
  самостоятельные кадры 16, 32 и 180 px без генеративной дорисовки. Проверить
  светлую и тёмную вкладки и публичную выдачу без старого векторного варианта.

## Первый экран и «Судовой журнал»

- [x] Вернуть первому экрану устойчивую высоту не меньше `100svh` и отдельно
  принять его композицию на десктопе и мобильном.
- [x] Довести стопку журнала: предыдущие карточки не исчезают, а переходят за
  текущую; под фотографией остаются только дата и заголовок без текстовой
  подложки; у фотографии нет декоративной или «призрачной» рамки.
- [x] После пяти отобранных записей заменять правую стрелку компактным
  действием «Журнал», не сдвигая центральный счётчик и не ломая одну строку.
- [x] У стрелок, карточек и ссылки на журнал должны быть явные hover-,
  focus-visible- и active-состояния. Переключение работает кнопками,
  клавишами ←/→ и со скринридером; `prefers-reduced-motion` соблюдается.
- [x] Все подложки элементов управления строить на одном токене материала
  «медуза». Текст и фотографии собственного материала не получают.

## Каталог и ассортимент

- [x] Привести каталог на главной и самостоятельную страницу каталога к одному
  компонентному и типографическому устройству, не уничтожая различие их задач.
- [x] Сохранить крупные исходные фотографии категорий и ясную связь названия,
  описания и цены. Разделители использовать только там, где они действительно
  связывают строку товара.
- [x] Проверить категории, поиск и фильтры на 320 px и при увеличении текста.
  Навигационный знак — один фирменный гарпун; у всей строки категории есть
  заметное состояние наведения и клавиатурного фокуса.

## Контакты, меню и завершение страницы

- [x] Собрать три равноправных контактных действия: «Позвонить», «Заказать в
  Телеграме» и «Заказать в WhatsApp». Телефон не дублируется отдельной строкой,
  WhatsApp не теряет форму кнопки; состояния взаимодействия едины.
- [x] Повторно проверить раскрытое меню: логотип и одна кнопка
  открытия/закрытия сидят на общей верхней оси в обоих состояниях, фон моря
  соответствует дневной или ночной вахте, лишние разделители отсутствуют.
- [x] Проверить мобильный подвал: нет чрезмерного пустого интервала, социальные
  каналы имеют один масштаб и ритм, а разделители обозначают реальные группы.
- [x] Провести сквозной аудит hover-, focus-visible- и active-состояний всех
  ссылок и кнопок. Механическая проверка дополняется реальным pointer- и
  keyboard-проходом.

## Сменная серия «Улов текущей вахты»

- [x] Создать отдельную, обратимую иллюстративную систему о том, что сегодня
  находится в руке капитана. Основной логотип, капитан, рука, иллюминатор,
  доски и надпись остаются неизменными; серия не подменяет основной знак.
- [x] Первый лист вариантов: селёдка, северная креветка, кальмар и осьминог.
  Каждый герой рисуется в той же гравюрной грамматике, а захват руки честно
  адаптируется к его анатомии — без вставки готового клипарта.
- [x] Связать исследовательские варианты с реальным ассортиментом и вручную
  отобранными записями «Судового журнала», но оставить их изолированными от
  живого интерфейса до отдельной визуальной приёмки.
- [x] Проверить каждый знак крупно, примерно в 120 px и в малом размере; не
  обещать автоматически использовать всю серию как фавиконы.

## Выпускной gate для каждого пункта

- [x] `pnpm lint` и `pnpm test`.
- [x] Реальный десктопный и мобильный рендер затронутой композиции.
- [x] Клавиатура, видимый фокус, reduced motion, 320 px и отсутствие
  горизонтального переполнения.
- [x] Отдельный коммит и push только целевой правки.
- [x] Завершение GitHub Pages и проверка публичного URL с обходом кэша.
