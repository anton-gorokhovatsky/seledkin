# Переключение ks.fish на GitHub Pages

Основной адрес: https://ks.fish/. Репозиторий:
https://github.com/anton-gorokhovatsky/seledkin.

## Сторона GitHub

1. Выпустить проверенный `main` через `.github/workflows/pages.yml` и проверить
   опубликованные страницы, каталог и новые записи журнала.
2. Установить `ks.fish` в **Settings → Pages → Custom domain**.
   При публикации через Actions файл `CNAME` сам по себе не меняет эту настройку.
3. Убедиться, что API Pages возвращает `cname: "ks.fish"`.
   До изменения DNS предупреждение о проверке домена ожидаемо.

Файл `CNAME` включён в артефакт. Канонические URL, Open Graph, JSON-LD,
robots.txt и sitemap.xml используют `https://ks.fish/`. Внутренние ссылки и
ресурсы относительные; страница 404 выбирает корень домена либо `/seledkin/`
на старом адресе GitHub Pages.

## Сторона регистратора

На 23 сентября 2026 года корневой домен указывает на Tilda: `185.129.100.112`.
Заменить эту A-запись четырьмя A-записями GitHub Pages:

| Тип | Имя | Значение |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | anton-gorokhovatsky.github.io |

Для `www` заменить прежнюю запись, если она есть. В CNAME нет `https://`
и `/seledkin/`. Остальные записи домена, включая почтовые MX и TXT,
сохраняются. Прежние A/AAAA для корня не должны направлять часть посетителей
на другой хостинг. IPv6 необязателен; на момент подготовки AAAA у корня нет.
Можно оставить TTL 600 секунд.

## После изменения DNS

Дождаться успешной проверки DNS в Pages и выпуска сертификата, затем включить
**Enforce HTTPS**, если GitHub не сохранил этот параметр автоматически.
Проверить `https://ks.fish/`, `/catalog/`, `/journal/`, `/about/`, страницу 404,
изображения и перенаправление `www.ks.fish` на основной адрес.
Распространение DNS и доступность HTTPS могут занять до 24 часов.

Настройка Pages не подтверждает, что регистратор уже изменил DNS или что
сертификат для домена выпущен. Эти состояния проверяются отдельно.

Официальная инструкция:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site
